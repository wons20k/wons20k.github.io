Projects

Patch-wise Retrieval: A Bag of Practical Techniques for Instance-level Matching
WACV 2026 project highlighting Patchify, a training-free and interpretable instance-level retrieval framework with localization-aware evaluation (LocScore).

Aligning What Vision-Language Models See and Perceive with Adaptive Information Flow (AIF)
A test-time information-flow modulation method for VLMs that identifies important visual tokens using token dynamics and suppresses distracting regions to improve perception-heavy tasks.

BEAF: Observing BEfore-AFter Changes to Evaluate Hallucination in Vision-language Models
Evaluates VLM hallucination by comparing answer changes between original and object-removed images, introducing change-aware metrics to assess true visual understanding.

VLM’s Eye Examination: Instruct and Inspect Visual Competency of Vision Language Model
Probes visual competency from color and shape to semantics through exam-style evaluation, and analyzes how model components affect fine-grained visual sensitivity.

SYNAuG: Exploiting Synthetic Data for Data Imbalance Problems
Uses synthetic data to rebalance skewed datasets with post-calibration, improving long-tail recognition, fairness, and robustness under imbalanced settings.
